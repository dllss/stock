## 策略逻辑（与 base 对齐）

状态机由 QQQ 价格驱动，6 个状态：

| 状态 | 触发条件 | 目标权重 |
|------|----------|----------|
| NORMAL | 站上 MA200 且回撤 < -10% | QQQ 45% / TQQQ 45% |
| ZONE_BATTLE_ATTACK | 熊市回撤 -10%~-30% 且站上 MA20 | TQQQ 99% |
| ZONE_BATTLE_DEFEND | 熊市回撤 -10%~-30% 且未站上 MA20 | QQQ 90% |
| ZONE_DESPAIR_TQQQ | 回撤 ≤ -30% | TQQQ 99% |
| BEAR_CASH | 跌破 MA200 且回撤 < -10% | 现金 100% |
| TOP_ESCAPE | 触及 ATH×0.95 且放量(Vol>VolMA×VOL_FACTOR)且收阴 | QQQ 90% |

- **逃顶过滤**：`close >= ATH×HIGH_ZONE` 且 `vol > VolMA×VOL_FACTOR` 且 `close < open`。
- **Anti-V 反转过滤**：risk-off → risk-on 需满足冷静期(`MIN_RISK_OFF_DAYS=2` 天) + MA20 斜率向上。
- **T+1 防融资**（与 base 一致）：状态切换日只卖出变现，`pending_buy` 推迟到下一交易日按目标权重买入。
- **NORMAL 再平衡**：QQQ/TQQQ 市值偏离 > 20% 触发再平衡。

## 实盘跟踪指导（`--live`）使用须知

`--live` 在回测日志末尾追加两块内容，**仅供参考，不改变策略逻辑**：

1. **次日状态切换地图**：列出 QQQ 价格临界点 → 目标状态 → 动作，供你盘中盯价。
2. **次日再平衡指令**：按最后一天收盘价估算买卖股数 + 目标权重。

注意事项：
- 指导中的「状态切换」指信号触发时点；**实际下单遵循 base 的 T+1**——切换日先卖变现，买入推迟到下一交易日。
- 逃顶量能条件需次日确认；盘中可用 `估算全天量 ≈ 当前成交量 ÷ 已过交易时间占比` 粗估（美股本日 6.5 小时），临近收盘最准。
- 股数以最后一天收盘价估算，实际下单请以实时价微调。

## 数据说明

- 数据源：东财美股（`secid = 105.{ticker}`），接口 `push2his.eastmoney.com`（App 历史 K 线同端点；实时 `push2` 对美股历史 K 线返回空）。
- 复权方式：**`qfq`（前复权）**，见下方「⚠️ 复权锚点漂移」——东财 qfq 的锚点**不稳定**，不同时间拉取历史尺度不同，近期价格仍 ≈ 实盘真实成交价（如 TQQQ≈72、QQQ≈715）。
- 缓存：`data/cache/` 下按 `{ticker}_{S.ADJUST}.csv` 命名（如 `TQQQ_qfq.csv` / `TQQQ_hfq.csv`），更新需重新拉取或删除缓存。
- 回测起点：`WARMUP_START` 预热算指标，`WARMUP_END` 后开始交易。

### 为什么用 qfq 而不是 hfq / raw（前复权 vs 后复权 vs 真实价）

回测的 `MIN_TRADE_VAL=500`（美元）与整股取整都是**绝对金额/绝对股数**阈值，其摩擦行为依赖价格尺度。三种口径对比：

| 口径 | 价格尺度 | 拆股跳空 | 与实盘 500 阈值摩擦贴合度 |
|------|----------|----------|----------------------------|
| `raw`（不复权/真实价） | = 真实价 | **有跳空**（拆股日 -50% 假阴线，会误触发回撤类状态） | 最优，但**不可用** |
| `hfq`（后复权） | 放大 ~400 倍（锚定上市首日） | 无 | 最差（阈值相对过小、整股截断按 400 倍放大，摩擦严重失真） |
| `qfq`（前复权） | 近期 ≈ 真实价 | 无 | **相对最优可用选择** |

结论：
1. **raw 淘汰**：跨拆股日会跳空，触发 `DESPAIR_LINE`/`BEAR_CASH` 等错误状态切换，回测失真。
2. **hfq 失真**：价格尺度被放大约 400 倍，500 美元阈值几乎永远触发、整股截断误差放大 400 倍，摩擦行为与实盘严重不符（实测收益被压低 ~4%）。
3. **qfq 相对优**：无拆股跳空；近期价格 ≈ 实盘真实价，500 阈值过滤与整股截断误差都和实盘一致；实盘建仓（2026-08-06）起即为真实价，直接可比。**但 qfq 的锚点由东财服务端决定、会漂移（见下），跨多年序列的历史尺度不可作为稳定基准。**

### ⚠️ 重要发现：东财 qfq 锚点漂移（以 TQQQ 为例）

> **历史教训（已纠正）**：早期本 README 曾写「前复权在多次拆股标的上造成假亏损 -56.87%」，该归因**错误**——qfq 本身并没有把拆股「撤销」。真实情况如下。

**事实链（实测核对，2026-08-08）**：
- TQQQ 真实上市首日（2011-01-26）收盘 = **167.01**（raw 不复权，东财接口实测确认）。
- TQQQ 自上市以来经历 **3 次 1:2 拆股**（股数 ×8、单价 ÷8，总资产不变）。
- 东财 `qfq` 接口的锚点**不是固定锚定最新日**：
  - 旧缓存（已删除，不可复现）首价 = **167.01** → 末价 ≈72，qfq 序列「从 167 跌到 72」，全仓买入持有据此算得 **-56.87%**。
  - **现在**实时拉取 qfq 首价 = **0.41**（Close 0.414），末价 ≈74，序列「从 0.41 涨到 74」→ 显示 **+17800%**。这与你在**东方财富 App 上看到的 qfq 首价 0.12** 是同一口径（App 与 `push2his` 同源，历史段被压低到拆股后量级）。
- 同一接口、同一标的，不同时间返回的历史尺度**相差约 400 倍**，证明**东财 qfq 锚点已漂移**。旧缓存是旧锚点残留，现已失效。

**真实根因**：全仓 TQQQ 长持的真实收益，根因是 **3× 杠杆 ETF 的波动衰减（volatility decay）+ 大回撤**，而非复权假象。若以稳定口径（hfq / raw）衡量，TQQQ 长期真实是暴涨（hfq 末价 ≈ 真实市价 72.9，相对上市 167 经拆股除权后量级约 +17000%），与「杠杆 ETF 长期跑输 3× 标的」理论一致。

**对回测的影响与用法建议**：

| 场景 | qfq 前复权可信度 |
|------|------------------|
| 双核策略（持续调仓，按每日真实市价交易） | ✅ 近期段可信（= 实盘价）；远古段受锚点漂移影响，但调仓消化大部分 |
| 全仓 QQQ（买入持有，QQQ 几乎不拆股） | ✅ 基本可信 |
| **全仓 TQQQ（买入持有）作为长期基准** | ❌ **不可信**（依赖东财飘忽的 qfq 锚点，数值随时变） |

- 含拆股标的的「买入持有」基准对照，若要稳定可复现口径，应改用 **raw（真实价）** 自行计算，而非依赖东财飘忽的 qfq 锚点。
- 回测现已**移除 hfq 支持**，全程统一使用 `qfq`（前复权）。`S.ADJUST` 固定为 `"qfq"`，`adjust_map` 仅保留 `qfq` 与 `""`(raw)。
- 报告中任何「全仓 TQQQ · 前复权」数值**必须标注抓取日期与锚点口径**，否则不可横向比较。

### 🔒 数据约束：TQQQ qfq 首日收盘价必须 < 1（而非 167）

东财 qfq 锚点会漂移：旧锚点返回首价 ≈167（锚定最新日），新锚点返回 ≈0.41（锚定上市首日除权，与 App 同源）。约束如下：

- **正确值**：新锚点下 TQQQ 首日（2011-01-26）收盘 ≈ **0.41**，末价 ≈74。
- **错误信号**：若拉取到的 TQQQ qfq 首日收盘价 **≥ 1**，说明落到了旧锚点口径，历史尺度被错误放大 ~400 倍，会污染回测（全仓 TQQQ 误判暴跌）。
- **人工动作**：遇到首价 ≥ 1 时**不得落盘**，应确认东财接口当前锚点口径（应锚定上市首日除权）后再重新拉取，不应用旧口径数据跑回测。

> 该约束仅针对 TQQQ qfq；QQQ（几乎不拆股、qfq 锚点稳定）与 raw(`""`) 口径不受此限。
