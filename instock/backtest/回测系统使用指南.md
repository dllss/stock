## 快速开始

### 基础命令

```bash
# 默认运行「量能突破」策略（最近1年）
python instock/backtest/backtest_strategy_job.py

# 运行指定策略
python instock/backtest/backtest_strategy_job.py breakthrough_volume
python instock/backtest/backtest_strategy_job.py turtle_trade
python instock/backtest/backtest_strategy_job.py backtrace_ma250

# 指定回测日期区间（策略 + 起始日 + 结束日）
python instock/backtest/backtest_strategy_job.py parking_apron 2024-01-01 2025-01-01

# 多策略对比（全部），可带日期
python instock/backtest/backtest_strategy_job.py all
python instock/backtest/backtest_strategy_job.py all 2025-01-01 2026-06-30

# 多策略对比（指定），可带日期
python instock/backtest/backtest_strategy_job.py compare:turtle_trade,keep_increasing,parking_apron
python instock/backtest/backtest_strategy_job.py compare:turtle_trade,keep_increasing 2025-01-01 2026-06-30

# 参数优化（默认优化 breakthrough_volume），可带日期
python instock/backtest/backtest_strategy_job.py optimize
python instock/backtest/backtest_strategy_job.py optimize:breakthrough_volume

# 参数优化 + 多策略 + 指定日期（最常用）
python instock/backtest/backtest_strategy_job.py optimize:turtle_trade,keep_increasing 2025-01-01 2026-06-30
```

### 回测输出

运行后会输出：

- **选股报告**：各项指标 Top 30 股票列表
- **交易明细**：每笔买入/卖出的日期、价格、收益
- **汇总统计**：总交易数、胜率、平均收益
- **账户模拟**：初始100万资金的最终收益、最大回撤

日志文件保存在 `instock/log/` 目录下。

## 10大策略详解

### 1. 海龟交易法则 (`turtle_trade`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 60天 |
| 可优化参数 | `break_days: [20, 30, 60, 90]` |

**买入条件**：当日收盘价 >= 最近N日最高收盘价（N 由 `break_days` 参数控制，默认60日）

**设计理念**：经典趋势跟踪，突破买入，不预测顶底，让利润奔跑。

---

### 2. 量能突破 (`breakthrough_volume`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 60天 |
| 可优化参数 | `break_days: [10,15,20,25]` / `vol_ratio: [1.2,1.5,2.0]` / `ma_days: [30,60,120]` |

**买入条件**（默认参数）：

1. 收盘价突破前20日最高价
2. 当日成交量 > 前5日均量 × 1.5倍
3. 收盘价在MA60均线之上

**设计理念**：双重确认突破——价格突破 + 放量配合，过滤假突破。

---

### 3. 突破平台 (`breakthrough_platform`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 120天 |
| 可优化参数 | 无 |

**买入条件**：

1. 60日内找到突破点：当日 `open < MA60 <= close`（向上突破60日均线）
2. 突破当天放量（量比 >= 2）
3. 突破前所有交易日收盘价与MA60偏离在 -5% ~ +20%（横盘确认）

**设计理念**：横盘整理后放量突破均线，确认趋势启动。

---

### 4. 回踩年线 (`backtrace_ma250`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 250天 |
| 可优化参数 | 无 |

**买入条件**：

1. 前段（最高价日之前）：从年线下方突破到年线上方
2. 后段（最高价日及之后）：所有收盘价不破年线
3. 回调时间 10~50 天
4. 缩量回调：最高价日量 / 最低价日量 > 2，且最低/最高 < 0.8

**设计理念**：牛股突破年线后缩量回踩，不破支撑确认有效。

---

### 5. 均线多头 (`keep_increasing`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 60天 |
| 可优化参数 | `ma_days: [10,20,30,60]` / `min_increase: [0.10,0.15,0.20]` |

**买入条件**：

1. MA30 在 30天/20天/10天/当天 四个检查点严格递增
2. 当天 MA30 > 30天前 MA30 × 1.2（月涨 > 20%）

**设计理念**：均线加速上行，捕捉主升浪初期。

---

### 6. 低ATR成长 (`low_atr`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 250天 |
| 可优化参数 | 无 |

**买入条件**：

1. 上市至少 250 天
2. 最近10天平均绝对涨跌幅 < 10%（低波动）
3. 10天内振幅 > 10%（`(最高价 - 最低价) / 最低价`）

**设计理念**：低波动稳步上涨，适合风险厌恶型投资者。

---

### 7. 无大幅回撤 (`low_backtrace`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 60天 |
| 可优化参数 | 无 |

**买入条件**：

1. 60日涨幅 >= 60%
2. 期间无单日跌幅 > 7%
3. 无当日高开低走 > 7%
4. 无两日累计跌 > 10%

**设计理念**：筛选强势上涨且无恐慌抛售的标的，表明资金控盘能力强。

---

### 8. 停机坪 (`parking_apron`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 20天 |
| 可优化参数 | 无 |

**买入条件**：

1. 近15日有涨停（涨 > 9.5%）且放量（量比 >= 1.5）
2. 涨停后第1天：高开于涨停价之上 + 涨跌幅在 -3% ~ +3%
3. 涨停后第2~3天：同样高开于涨停价，涨跌幅 -5% ~ +5%，且当日开收在 ±3% 内，收盘价始终高于涨停价

**设计理念**：涨停后高位横盘不回落，是强势股洗盘的经典形态。

---

### 9. 高而窄旗形 (`high_tight_flag`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 60天 |
| 可优化参数 | 无 |

**买入条件**：

1. 24~10天前的14天区间内：末日前高价 / 区间最低价 >= 1.9（涨90%+）
2. 该区间内存在连续2天涨 >= 9.5%
3. 当前日期距离区间结束至少 10 天（窄幅整理窗口）

**设计理念**：捕捉短期内暴涨后窄幅整理的"旗形"突破。（原策略含机构参与度过滤，回测版已简化）

---

### 10. 放量跌停 (`climax_limitdown`)

| 项目 | 说明 |
|------|------|
| 最小K线 | 61天 |
| 可优化参数 | 无 |
| 风险等级 | ⚠️ 高风险 |

**买入条件**：

1. 当日跌幅 >= 9.5%（接近跌停）
2. 成交额 >= 2亿
3. 当日成交量 / 5日均量 >= 4倍（巨量恐慌盘）

**设计理念**：极端恐慌后的反弹博弈，高风险高回报，适合小仓位参与。

## 卖出机制

所有策略共用同一套卖出规则，4种触发条件：

| 条件 | 参数 | 默认值 | 逻辑 |
|------|------|--------|------|
| 止损 | `stop_loss` | -8% | 浮亏 >= 8%，立即卖出 |
| 止盈 | `stop_profit` | +20% | 浮盈 >= 20%，立即卖出 |
| 移动止损 | `trailing_stop` | -5% | 曾浮盈 >= 6%（`trailing_stop_activation`），从最高点回落 >= 5% |
| 最大持仓 | `max_hold_days` | 60天 | 持仓超60天仍未触发上述条件，强制卖出 |

此外回测结束时所有未平仓头寸会被强制以最后一日开盘价平仓（与 `backtest_stock` 单股回测保持一致）。

## 参数优化

### 卖出参数网格

| 参数 | 候选值 | 组合数 |
|------|--------|--------|
| `stop_loss` | -5%, -8%, -10% | 3 |
| `stop_profit` | 15%, 20%, 25%, 30% | 4 |
| `trailing_stop` | -3%, -5%, -8% | 3 |
| `trailing_stop_activation` | 3%, 6%, 10%, 15% | 4 |
| `max_hold_days` | 30, 60, 90, 120 | 4 |

卖出参数组合：**3 × 4 × 3 × 4 × 4 = 576 种**

### 策略参数网格

| 策略 | 参数 | 候选值 | 组合数 |
|------|------|--------|--------|
| 量能突破 | `break_days` | 10, 15, 20, 25 | 4 |
| | `vol_ratio` | 1.2, 1.5, 2.0 | 3 |
| | `ma_days` | 30, 60, 120 | 3 |
| 海龟交易 | `break_days` | 20, 30, 60, 90 | 4 |
| 均线多头 | `ma_days` | 10, 20, 30, 60 | 4 |
| | `min_increase` | 0.10, 0.15, 0.20 | 3 |

### 优化总组合数（全量网格）

| 策略 | 策略参数 × 卖出参数 | 总组合 | 全量耗时 |
|------|---------------------|--------|----------|
| 量能突破 | 4×3×3 × 3×4×3×4×4 | **20736** | 28~56 小时 |
| 海龟交易 | 4 × 3×4×3×4×4 | **2304** | 3~7 小时 |
| 均线多头 | 4×3 × 3×4×3×4×4 | **6912** | 9~18 小时 |
| 其他（7个） | 1 × 3×4×3×4×4 | **576** | 50~100 分钟 |

### 加速方案（默认已启用）

`run_optimize()` 默认使用 **两阶段优化** + **抽样500只股票**，大幅缩短耗时：

| 方案 | 原理 | 量能突破耗时 |
|------|------|-------------|
| **两阶段优化**（默认） | 先定卖出参数(576组) → 再定策略参数(36组) = 612组 | **50~100 分钟** |
| **随机搜索** | 从20736组中随机抽300组 | **25~50 分钟** |
| **两阶段+抽样**（默认） | 612组 × 500只股票 | **10~25 分钟** |
| 全量网格 | 20736组 × 全市场 | 28~56 小时 |

> **为什么两阶段有效？**：卖出参数（止损/止盈/移动止损/移动止损激活阈值/持仓天数）和策略参数（突破天数/量比/均线天数）之间存在相当大的独立性。分开优化将 N×M 降为 N+M，对量能突破就是从 20736 → 612 组。

### 命令行控制

```bash
# 默认：两阶段优化 + 500只抽样（单策略 + 默认最近1年）
python instock/backtest/backtest_strategy_job.py optimize:breakthrough_volume

# 多策略优化 + 指定日期
python instock/backtest/backtest_strategy_job.py optimize:turtle_trade,keep_increasing 2025-01-01 2026-06-30

# 代码内切换模式
# mode='two_phase'   两阶段（默认）
# mode='random'      随机搜索300轮
# mode='grid'        完整网格（最慢）
# sample_size=0      不抽样，用全市场股票
# sample_size=500    抽样500只（默认）

# 示例：修改 instock/backtest/backtest_strategy_job.py 的 run_optimize() 调用
# run_optimize(kline_dict, start, end, strategy_id, mode='random', n_iter=300, sample_size=200)
```

### 优化策略建议

```
第一轮（摸底）：  mode='random', n_iter=200, sample_size=300  →  ~3分钟
第二轮（精调）：  mode='two_phase', sample_size=0             →  ~25分钟
第三轮（确认）：  mode='grid',     sample_size=0             →  扔后台跑一夜
```

## 回测架构

### 完整执行流程（6步）

```
main()
  │
  ├─ 1. 确定回测区间（默认最近1年）
  ├─ 2. 初始化日志 → instock/log/策略名_时间戳.log
  │
  ├─ 3. load_kline_data()
  │     └─ 从 MySQL cn_stock_spot 表加载K线
  │        └─ 往前多取300天（供回踩年线等长周期策略使用）
  │
  ├─ 4. 分发到具体模式
  │     ├─ run_single_strategy()     → 单个策略
  │     ├─ run_compare()             → 多策略对比
  │     └─ run_optimize()            → 参数优化（枚举所有组合）
  │
  ├─ 5. run_backtest() 核心引擎
  │     ├─ 准备每只股票一个任务 (code, kline, strategy_id, params, ...)
  │     ├─ <10只股票串行，≥10只并行（CPU核心数-1）
  │     │    └─ ProcessPoolExecutor → _backtest_single_stock() → backtest_stock()
  │     │         ├─ 过滤日期范围
  │     │         ├─ 从第 min_data 天开始逐日扫描
  │     │         │   ├─ 如有 pending_sell → 今天以开盘价卖出（T+1）
  │     │         │   ├─ 如有 pending_buy  → 今天以开盘价买入（T+1）
  │     │         │   ├─ 持仓中 → 检查 止损/止盈/移动止损/最大持仓
  │     │         │   └─ 空仓中 → 调用 signal_func() 检测选股信号
  │     │         └─ 回测结束 → 强制平仓所有持仓
  │     └─ 汇总所有 Trade 对象
  │
  └─ 6. 统计输出
        ├─ summarize()          汇总（胜率/盈亏比/按卖出原因统计）
        ├─ print_summary()      格式化输出
        ├─ print_trades()       盈利 & 亏损 TOP 30 交易明细
        ├─ simulate_portfolio() 资金账户模拟
        │    ├─ 逐日遍历完整日历（含 T+1 扩展）
        │    ├─ 先卖后买，满仓则跳过买入
        │    ├─ 每只分配 10万（100股整数倍）
        │    ├─ 佣金 0.025% + 印花税 0.05%（卖出单边）
        │    └─ 回测结束：强制平仓 + 到账所有 pending 资金
        └─ print_comparison()   多策略对比表
```

### 交易时序（T+1 模拟）

```
Day T:    收盘后检测信号
          ├─ 买入信号 → pending_buy = True
          └─ 卖出信号 → pending_sell = True, 记录 reason

Day T+1:  以开盘价执行 pending 订单
          ├─ pending_sell: 以开盘价卖出 → 资金记录到 T+2 pending_cash
          ├─ pending_buy:  以开盘价买入 → 扣费
          └─ 买入当天不检查卖出

Day T+2:  卖出资金到账（update_pending_cash），可重新买入
```

### 关键交易规则

| 规则 | 说明 |
|------|------|
| **T+1 交易** | 今天触发信号 → 明天以开盘价成交 |
| **T+1 资金** | 卖出后资金第二天才到账可用 |
| **卖出优先级** | 止损 -8% > 止盈 +20% > 移动止损 -5% > 最大持仓 60天 |
| **移动止损触发** | 浮盈曾 ≥ `trailing_stop_activation`（默认6%）且从最高点回落 ≥ `trailing_stop`（默认5%） |
| **资金分配** | 每只 100万/10 = 10万，100股整数倍，满仓则跳过 |
| **手续费** | 佣金 0.025%（最低5元）+ 印花税 0.05%（卖出单边） |
| **并行处理** | <10只股票串行，≥10 只用 ProcessPoolExecutor |
| **回测结束** | 强制平仓所有持仓 + 到账所有 pending 资金 |

## 关键配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `initial_cash` | 1,000,000 元 | 初始资金 |
| `max_positions` | 10 | 最大同时持仓数（每只10万） |
| `buffer_days` | 300天 | 往前多加载的历史数据 |
| `n_workers` | CPU核数 - 1 | 并行进程数 |
| 佣金 | 0.025%（最低5元） | 双边收取 |
| 印花税 | 0.05% | 仅卖出单边 |
